## 二、跨问冻结接口（`interfaces/`）

跨问传递的唯一权威接口，SHA-256 已与问题一冻结值逐位比对通过。

| 文件 | 说明 |
|---|---|
| `Q1_M2响应接口.csv.gz` | 问题一配比响应接口（17 维配比 → 13 目标对数 Loss 响应，577 行） |

| `mix_final_model_quad.csv` | 配比二次模型系数（问题三/四最新版中已降级为对照材料） |
| `Q1_p0_17dim.csv` | 参考配比 p₀（17 维，取 A4 训练配方逐域均值） |

> `Q1_M2响应接口.csv.gz` 与 `mix_final_model_quad.csv` 为问题二、三、四交付包共同引用的冻结件；哈希一致即表示各问使用的是同一份接口。

## 四、复现路径映射

源码使用仓库根相对路径（`data/real_attachments/…`、`src/…`、`configs/…`、`tests/…`）。若要直接重跑，请先把本仓库按下列方式映射为仓库布局：

| 本仓库路径 | 需映射为 |
|---|---|
| 赛题附件（需另行获取） | `data/real_attachments/` |
| `code/src/` | `src/` |
| `code/configs/` | `configs/` |
| `code/tests/` | `tests/` |

运行顺序：问题一 → 问题二 → 问题三 → 问题四（顺序依赖，见 README 第七节）。

## 五、证据纪律

1. 半合成数据（B2、B6、B7、B8）须标注，不得表述为直接实验观测。
2. 估算数据（A12–A15、B10）不得作为独立验证。
3. λ_p、质量成本函数 g(Q)、η 未被联合实验识别，只能以情景族 + 包络形式报告。
4. 跨问数值一律引用 `interfaces/` 的冻结件，不引用历史版本。
5. 口径不可唯一识别的量（如 g_N）须报区间或敏感曲线。
