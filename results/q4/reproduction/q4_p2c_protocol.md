# 问题四 P2-C 预注册回测协议（v1，冻结）

冻结时间：2026-09-26
冻结方式：本文件内容在回测执行前写定；`q4_p2c_backtest.py` 在运行前校验本文件的 SHA-256，不一致即中止。

## 0. 为什么需要预注册

问题四的核心交付是"12/24 个月前沿预测 + 区间"。此前所有区间都是**解析构造**（残差 σ × √h），
没有任何**经验覆盖率**检验。若在看到结果后再挑模型/口径/判据，回测会退化为"事后叙述"。
因此本节先把**模型族、口径、判据、禁止事项**写死，再执行回测。

## 1. 回测对象与数据口径（冻结）

| 项 | 冻结取值 |
|---|---|
| 数据文件 | `C_efficiency_evolution/leaderboard_cleaned.csv` |
| 样本口径 | OPEN_LIC：`Hub License` 命中许可白名单（apache, mit, bsd, llama, gemma, cc-by, openrail, gpl, wtfpl, afl, creativeml, bigscience, bigcode, apple-ascl） |
| 时间分辨率 | 月度 `Period('M')` |
| 有效窗口 | 2024-06 ~ 2025-03（**10 个月**） |
| 前沿定义 | F_m = quantile_0.90(S \| 月份 m)，S = `Average ⬆️` |
| 目标变换 | y_m = ln F_m |
| 最小训练长度 | 4 个月 |
| 预测步长集合 | h ∈ {1, 2, 3} 个月 |

**不采用 C3 年度序列做回测**：其"累计最大前沿"在 2019–2023 恒为 50.00、2024–2025 为 52.08，
是退化阶梯，不含可检验的时序变异。此判定在回测前作出。

## 2. 模型族（冻结，共 4 个）

记 origin 处最后观测为 S_L、对数前沿序列为 y，月度索引 t=0..n-1。

- **M1 有界 logistic**
  A = (100 − S_L)/S_L，r = g/(1 − S_L/100)，Ŝ(h) = 100/(1 + A·e^(−r·h))
- **M2 无界对数线性**
  Ŝ(h) = S_L·exp(g·h)
- **M3 随机游走（持久）**
  Ŝ(h) = S_L
- **M4 外生固定增速（情景常量）**
  同 M2，但 g 不估计，固定为 g = 0.6326/年（= 问题四腿2 全样本估计，作为"不做滚动估计"的对照）

## 3. 增速估计规则（冻结）

g = OLS slope(y ~ t) × 12（年化），**仅使用 origin 及之前的点**，最小二乘、无正则、无加权。

## 4. 预测区间构造（冻结）

- 对数残差标准差：σ_y = sqrt( SSE/(n−2) )，SSE 来自 origin 前的 OLS 拟合。
- 步长缩放：σ_h = σ_y · √h。
- M1 在 logit 尺度、M2/M4 在 ln 尺度构造分位区间后映射回 S 尺度；
  M3 无拟合残差，取 σ_h = σ_y^{M2} · √(h+1)（含 1 步外推不确定，保守）。
- 名义水平：80%（z=1.2816）与 90%（z=1.6449）。

## 5. 评估指标（冻结）

逐 (origin, h) 计算误差 e = S_real − S_pred（S 尺度），另记 e_ln = ln S_real − ln Ŝ。

- MAE、RMSE、bias（均值误差）
- 90% 与 80% 区间**经验覆盖率**
- pinball@0.90（S 尺度，τ=0.9）
- 方向正确率：sign(S_pred − S_L) 与 sign(S_real − S_L) 一致的比例

汇总口径：pooled（全部 (origin,h) 合并）。

## 6. 预注册通过判据（冻结，三选全过才算通过）

- **C1（不劣于持久）**：pooled RMSE(M1) ≤ pooled RMSE(M3)
- **C2（区间校准）**：90% 区间经验覆盖率 ∈ [0.50, 1.00]（小样本宽容下限）
- **C3（无系统偏差）**：bias(M1) 的 t 统计量 |t| < 2

## 7. 校准输出（冻结）

- κ = median( |e_ln| / σ_h )，作为"实际对数误差 / 名义对数不确定度"的校准系数。
- 若 κ > 1，则 12/24 个月预测区间须按 κ 放大后报告；若 κ < 1，**仍不缩小区间**（保守原则）。

## 8. 禁止事项（冻结）

1. 不得在看到回测结果后修改模型族、样本口径、窗口、判据。
2. 不得使用测试点（i+h）参与任何拟合、超参或口径选择。
3. 不得用回测结果反推 g；回测只检验**流程**，不重估问题四主结论的 g。
4. 不得因回测样本量小（pooled 15 个点）而省略"低功效"声明。

## 9. 已知局限（回测前声明）

- pooled 检验样本仅 15 个 (origin, h) 组合，统计功效极低；覆盖率判据只能作**证伪下限**，不能作精度证明。
- h 最大 3 个月，而主预测是 12/24 个月；σ_h = σ_y·√h 的线性缩放假设本身**未被回测覆盖**。
- 月度 p90 由当月少量模型估计（早期月份 n≈130），前沿值本身带测量噪声，会同时抬高 M3 与 M1 的误差。
