# 团队交付包修订重跑说明

## 本次修正

1. 第一题模型改为当前正式选定的 LightGBM，模型 SHA-256 为
   `39c5d5dc13b6f0fbf68699bb45d2d8d18e28f81f0f46f5475311e6aa66bd1c33`；
   不再使用旧包中的二次响应表代理模型。
2. 配比与 Loss 全部按原始 `index` 一一连接，配方标识使用实际索引；不再按
   Python 的零基循环号生成 `recipe_id`。
3. 17 维配比先逐行归一化到单纯形，再输入冻结模型；原始行和单独保留在正式
   接口中。
4. 不沿用旧包把 `E=1.7112` 与 `+0.1027(1-Q)` 同时代入的参数化。该写法会
   重复增加 0.1027；本次质量模型直接重新拟合，并在相同组折上比较 M0/MQ。
5. `Q_A→Q_B`、`lambda_p` 和 Form A/B 没有联合观测可供识别，均保留为语义
   隔离或显式情景，不报告伪精确的唯一估计值。

## 重跑结果

- Q1→Q2 正式接口：`PASS`；1214 个配方，17 输入、13 输出。
- B1 留一规模宏 RMSE：0.000146888。
- B6 组交叉验证宏 RMSE：M0=0.128762，MQ=0.0760865。
- B7-new（90 行）RMSE：M0=0.0589578，MQ=0.0490942。
- B8：150/150 个分层组的 Q–Loss Spearman 为正，方向与 B6/B7 主模型相反。

因此，重跑支持“B6/B7 半合成体系内加入 Q_B 能改善预测”，但不支持把 B8
与其合成一个统一质量效应，也不支持声称第一题质量分数可直接转换成 B 附件的
Q_score。配比作用只能按第一题冻结模型给出条件情景，不能解释为附件 B 已识别
的因果效应。
